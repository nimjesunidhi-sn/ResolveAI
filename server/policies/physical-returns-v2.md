# Return window
Physical goods may be refunded within 30 calendar days after delivery when unused or defective. The order must be marked delivered and belong to the customer requesting help.

# Damage evidence
For a damaged, broken, or defective item, ask for a photograph or other reasonable evidence and verify the delivery date. Missing evidence requires a human agent to review the request; it does not by itself authorize a refund.

# Duplicate requests
Do not refund an order or transaction more than once. Check refund history before creating any refund request.
