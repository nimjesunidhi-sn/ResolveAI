# Duplicate charges
Verify both transactions and their amounts before deciding whether a duplicate charge should be refunded. Do not create a second refund for the same transaction.

# Unauthorized activity
Suspected unauthorized activity, fraud, or a chargeback must be escalated to a specialist for human review.
